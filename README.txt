# Ibtihel & Mahdi Invitation

## Put your assets in `/assets`

Required files:

- cover-desktop.mp4
- cover-mobile.mp4
- cover-desktop.jpg
- cover-mobile.jpg
- couple.jpg
- stamp.png
- song.mp3

The JPG files are automatic fallbacks if a video cannot load.

Open `index.html` in a browser, or deploy the folder to Netlify, Vercel, GitHub Pages, etc.

Music:
- The song is set to loop.
- It attempts to start immediately.
- Some mobile browsers block sound autoplay until the first touch/click. The first interaction will start it automatically.
- Music continues when opening the invitation and only pauses when the user presses the music button.
