# Mehdi & Ibtihal — Virtual Engagement Invitation

## Run locally
Open `index.html` in a browser.

The uploaded couple photo is already included at:
`assets/couple.png`

## Optional music
Add an MP3 file named:
`assets/music.mp3`

The music button is already implemented. Most mobile browsers require the visitor to interact with the page before audio can play, so the invitation attempts to start the music after "افتحوا دعوتنا" is pressed.

## Publish online
Upload the whole `virtual_invitation` folder to any static hosting service or web server.

The invitation is responsive and designed primarily for mobile screens.
